Review before adoption

  1. Identify the upstream repository, maintainer and immutable version.
  2. Record the licence, attribution requirements and provenance of included data and code.
  3. Inspect dependencies and installation behaviour; assess security findings before execution.
  4. Test the intended integration and keep the test inputs, outputs and limitations with the result.

A package listing or discovery card alone does not demonstrate a working integration or a security assessment.
